# Brew Haven Coffee

A simple and elegant **coffee shop landing page** built using HTML and CSS. Brew Haven provides a clean interface to showcase popular coffee items, customer reviews, and café information.

## Features

* Attractive coffee shop landing page
* Home/Hero section
* Popular Coffee menu
* Customer Reviews section
* Why Choose Brew Haven section
* Contact information
* Responsive viewport setup
* Clean and simple UI

## Menu

The website currently showcases:

| Coffee     | Price |
| ---------- | ----: |
| Espresso   |  ₹149 |
| Cappuccino |  ₹199 |
| Latte      |  ₹179 |

Each coffee card includes an image, name, description, and price.

## Technologies Used

* **HTML5**
* **CSS3**
* **Unsplash Images**

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/brew-haven.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd brew-haven
```

### 3. Run the website

Simply open `index.html` in your browser.

You can also use **Live Server** in VS Code for a better development experience.
